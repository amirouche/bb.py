# Bonjour le monde depuis bb (aussi connu sous le nom de beyond babel)

Beyond Babel (bb, aussi connu sous le nom de beyond babel) est un gestionnaire de pool de fonctions pour Python qui permet le partage de fonctions multilingues à travers la normalisation AST et le stockage adressé par contenu.

La raison d'être de bb (aussi connu sous le nom de beyond babel) est de permettre aux développeurs du monde entier de partager la même logique de fonction, indépendamment de la langue humaine utilisée pour nommer les variables, les paramètres et documenter le code. Une fonction écrite en français avec des noms de variables français produira le même hash qu'une fonction identique écrite en anglais avec des noms de variables anglais, car seule la logique compte, pas la présentation.

Ce projet brise les barrières linguistiques dans le développement logiciel et favorise une véritable collaboration internationale où chaque développeur peut travailler dans sa langue maternelle tout en partageant du code avec le monde entier.
