# Hello world from bb (also known as beyond babel)

Beyond Babel (bb, also known as beyond babel) is a function pool manager for Python that enables multilingual function sharing through AST normalization and content-addressed storage.

The reason for bb (also known as beyond babel)'s existence is to allow developers from around the world to share the same function logic, regardless of the human language used to name variables, parameters, and document the code. A function written in French with French variable names will produce the same hash as an identical function written in English with English variable names, because only the logic matters, not the presentation.

This project breaks down language barriers in software development and fosters true international collaboration where each developer can work in their native language while sharing code with the entire world.
